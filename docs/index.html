Spot what's in a model's training data — stage sizes, exact mix composition, and how much of post-training is about being helpful, honest, and harmless. A base model with no post-training shows the pretraining half alone. The datasets tabs run the same layers over a dataset on its own: it arrives as a single stage, with no training pipeline around it and no response anything was fit to.

Mix composition is counted, not sampled: it comes from each dataset's own label columns via the HuggingFace datasets-server, over every row that server reached — which on the largest mixes is a fraction of the split, and the stage says which fraction. HHH shares are estimated from prompts sampled per stage and labeled with Claude; whiskers are Wilson 95% intervals. Click any bar for the prompts behind it, then see it in training context for the rest of the training example — the response the model is fit to, the pair it is pushed between, or the verifier that scores it. On a dataset tab those same labels describe what the person asked for: nothing was trained on a chat log, so there is no training signal there to read. Search finds a literal string anywhere in those samples, responses and reference answers included, across every model at once; it reads 300 rows per stage, so it finds instances rather than a rate. Language is detected locally per prompt, line by line and weighted by length, so a template that wraps a foreign-language question in English instructions counts as English; a prompt split evenly between two languages is left undetermined rather than assigned to one. Data: Ai2's OLMo 3 release (Dolma 3 / Dolci) and EleutherAI's Pythia (the Pile) — except the is my writing in here? tab, which counts exact strings in the older public corpora that have an infini-gram index: Dolma 1.7, DCLM-baseline, RedPajama, C4 and the Pile. No public index covers Dolma 3, so for the OLMo 3 models that tab describes neighbouring corpora rather than what they read; for Pythia the Pile index is the corpus itself, give or take deduplication.
