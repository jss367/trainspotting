Spot what's in a model's training data — stage sizes, exact mix composition, and how much of post-training is about being helpful, honest, and harmless.

GitHub ↗
Mix composition is exact (from each dataset's own label columns via the HuggingFace datasets-server). HHH shares are estimated from prompts sampled per stage and labeled with Claude; whiskers are Wilson 95% intervals. Click any bar for the prompts behind it, then see it in training context for the rest of the training example — the response the model is fit to, the pair it is pushed between, or the verifier that scores it. Language is detected locally per prompt, line by line and weighted by length, so a template that wraps a foreign-language question in English instructions counts as English; a prompt split evenly between two languages is left undetermined rather than assigned to one. Data: Ai2's OLMo 3 release (Dolma 3 / Dolci). Regenerate with trainspotting classify, trainspotting context + scripts/export_site_data.py.
